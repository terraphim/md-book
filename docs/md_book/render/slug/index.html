Module slug 

Source
Expand description

GitHub-compatible heading slugs with per-page collision counters.

“Compatible” means the same shape as GitHub’s slugger: lowercased, runs of separators collapsed to one dash, punctuation dropped, Unicode letters kept. Dropping non-ASCII would give every heading in a Cyrillic or CJK book the same section-N anchor.
